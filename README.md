# IGFS - International Global Future Studies

A modern, responsive website for International Global Future Studies - your gateway to study abroad opportunities and educational consulting services.

## 🌍 Overview

This project is a professional website built with React, TypeScript, and Tailwind CSS. It features a modern design with dark mode support, smooth animations, and a comprehensive blog system for educational content.

## 🚀 Features

- **Responsive Design** - Works on all devices (mobile, tablet, desktop)
- **Dark Mode** - Toggle between light and dark themes
- **Smooth Animations** - Framer Motion powered transitions and interactions
- **Blog System** - Complete blog with listing and single post pages
- **Modern UI/UX** - Clean, professional design with intuitive navigation
- **Performance Optimized** - Fast loading and optimized assets
- **Accessibility** - WCAG compliant design practices

## 🛠️ Tech Stack

- **Frontend**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Animations**: Framer Motion
- **Deployment**: Vite.js + GitHub Pages
- **Icons**: Custom SVG components
- **State Management**: React Context API
